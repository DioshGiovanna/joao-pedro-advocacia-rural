# João Pedro Carvalho — Advocacia rural

Site estático para GitHub Pages. Sem instalação ou dependências.

## Arquivos
- index.html: conteúdo e estrutura
- style.css: visual e responsividade
- script.js: botão de contato durante a leitura
- joao-pedro.jpg: retrato

## Como editar
Abra o arquivo desejado no GitHub, clique no lápis e salve um commit na branch main. O Pages publica a branch main, pasta raiz.

## Colaboração
Colaboradores convidados podem editar diretamente. Outras pessoas podem fazer fork e abrir pull request.

Preserve as credenciais confirmadas e contatos. Não acrescente promessas de resultado ou experiência não verificada.
